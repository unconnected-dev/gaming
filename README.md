## Gaming

This repository serves as a sandbox for experimenting with front-end game mechanics using **TypeScript** and **PIXI.js**. Each subdirectory represents a standalone prototype focusing on different interactive concepts.

---
#### Structure
- `clusterGame/` – A cluster game prototype demonstrating tile matching and group detection logic.
- `lotteryTicket/` – A lottery-style number selection game where players choose numbers and compare them against randomized results.
- `rollup/` – An experimental concept for presenting large win rollups using alternative animation and pacing techniques.

---
#### Getting Started

To run any of the prototypes:

1. Navigate to the desired project directory:
   ```bash
   cd [project-directory]
2. Install dependencies:
   ```bash
   npm install
3. Start development server
   ```bash
   npm start
